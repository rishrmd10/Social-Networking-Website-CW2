# Manchester United Stand

A full-stack web application developed as part of my **Web Applications & Development** coursework. **Manchester United Stand** is a fan-focused platform designed to bring Manchester United supporters together by providing a space to share posts, upload images, and engage with content related to the club.

This project demonstrates my understanding of full-stack web development, combining a responsive frontend with a Node.js and Express backend, alongside MongoDB for data storage.
