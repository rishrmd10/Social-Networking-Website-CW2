# Manchester United Stand

A full-stack web application developed as part of my **Web Applications & Development** coursework. **Manchester United Stand** is a fan-focused platform designed to bring Manchester United supporters together by providing a space to share posts, upload images, and engage with content related to the club.

This project demonstrates my understanding of full-stack web development, combining a responsive frontend with a Node.js and Express backend, alongside MongoDB for data storage.

## Installation

### Clone the repository

```bash
git clone https://github.com/rishrmd10/Social-Networking-Website-CW2.git
```

### Navigate to the project folder

```bash
cd Social-Networking-Website-CW2/Code
```

### Install dependencies

```bash
npm install
```

### Start MongoDB

Ensure that MongoDB is installed and running locally.

### Run the application

```bash
node server.mjs
```

The application will then be available in your browser.

---

## Database

The repository includes a MongoDB database export:

```
MONGO DUMP - socialnetwork full.json
```

Import this file into MongoDB to populate the application with the sample data provided.
